# CatSpot

CatSpot is a web map for the cats that quietly occupy a neighbourhood. It turns the everyday question "Was that the ginger one from yesterday?" into a shared field record: a colour, a temperament, a time and an approximate place.

## Browse the sightings

The map gathers cat-shaped markers and clusters them when many sightings are close together. Use the All Cats, Today and Nearby counts to open matching records; Nearby follows the position you choose to share with the browser. Select a pin or a record to see the cat's colour, whether it was friendly, when it was spotted and its approximate area.

## Add a pawprint

File a sighting by choosing a coat colour and whether the cat cooperated with the survey. CatSpot uses your current position to place the record, then shows it on the map. The catalogue includes ginger, black, white, grey, tabby, calico, mixed and other cats; the form does not ask you to create an account.

## Approximate by design

The public map does not publish the exact point captured by the phone. A sighting's displayed coordinate is shifted before it is shown, and the map gives an approximate area rather than a doorstep. That leaves enough geography for a neighbourhood record without turning a passing cat's location into a precise address.
